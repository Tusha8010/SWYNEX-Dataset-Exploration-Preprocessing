# SWYNEX-Dataset-Exploration-Preprocessing

## Task 1 – Dataset Exploration & Preprocessing

This project prepares the Titanic Passenger Dataset for machine learning.

### Objectives
- Explore the dataset
- Analyze missing values and duplicates
- Perform exploratory data analysis
- Engineer useful features
- Handle missing values
- Encode categorical variables
- Split data into training/testing sets
- Scale numerical features

### Dataset
Titanic Passenger Dataset. Target variable: `Survived`.

### Project Structure
```text
SWYNEX-Dataset-Exploration-Preprocessing/
├── SWYNEX_Dataset_Exploration_Preprocessing.ipynb
├── README.md
├── requirements.txt
└── data/
    └── titanic.csv
```

### Preprocessing
1. Missing-value analysis
2. Cabin deck feature engineering
3. Feature/target separation
4. Train-test split
5. Median imputation for numerical values
6. Most-frequent imputation for categorical values
7. One-hot encoding
8. Standard scaling

### Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook.

### Run
```bash
pip install -r requirements.txt
jupyter notebook
```
